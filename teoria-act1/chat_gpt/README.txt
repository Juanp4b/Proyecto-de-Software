IMPORTANTE

El sitio no utiliza JavaScript ni otro script. HTML/CSS puro no puede leer el contenido de un directorio ni detectar automáticamente coincidencias entre archivos.

Para agregar una mascota, usar el mismo nombre base en ambas carpetas. Ejemplo:
imagenes/perro_7.jpg
info/perro_7.pdf

Después agregar manualmente la tarjeta correspondiente en index.html y la opción correspondiente en contacto.html.
